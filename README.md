# 遇见桂林山水 · Where Mountains Meet Water

用于“中国文化与国际传播”课程的中英文互动网站。

## 本地打开

所有运行文件位于 `dist/`，无需安装依赖。在项目目录执行 `node preview.cjs`，访问 `http://localhost:4173`。建议通过本地预览服务或线上网址使用照片明信片导出，避免浏览器对直接打开本地图片的安全限制。

## 互动

- 正文、景点故事、地貌说明、诗画背景与标题直接中英对照；顶部语言按钮调整阅读优先顺序并保存偏好。
- “说山水 / Connect”课程板块：解释山水（shanshui）、留白（liubai）和意境（yijing），提供拼音、英文表达、双语示例与来源。
- 课程板块按文化词汇、英语介绍两步纵向展开；电脑端介绍双语等宽并排，窄屏改为上下阅读。全站使用分语言字体、统一正文层级和间距，结尾双语居中对齐。
- 英语介绍练习：三处景点 × 三个文化概念 × 三类受众，生成27种带中文对照的英语介绍参考，可一键复制，包含引入、解释与互动提问。`node test-course.cjs` 检查内容与初始化顺序。
- 跨文化讨论与负责任传播提示：邀请听众讲述熟悉的风景，交代诗歌语境，保留照片授权与原作来源。
- 点击竹筏启程，过渡进入沿江探索。
- 象鼻山、九马画山、兴坪黄布景观段三处实景探索；路线标记切换全景，点击照片上的细节标记可分别靠近水月洞、画山岩壁和峰林层次。支持返回全景，附位置、观察提示和资料来源。
- 景点预览使用1280px WebP并提前解码缓存，三张合计约410KB（原照片约1.70MB）。只有最后一次选择可以更新照片和文字；慢加载或失败时保留匹配的当前图文。细节与明信片按需共享1920px图片。`node test-scenic.cjs` 验证快速切换、图片解码时序、失败重试及相机边界。
- 可拖动、播放、跳转阶段的地貌过程示意；支持地表立体地形与地下剖面两个视图。
- 水滴路径小游戏：点击或拖动、支路退回、路线提示、放水动画与长期溶蚀结果。
- 游戏按画面上的连线判定，仅有一条入口到出口的通路；其余为可退回的支路。18与19之间的断口在画面和规则中保持一致。`node test-fractures.cjs` 会枚举通路验证唯一解，并检查支路退回和所有节点的路线提示。
- 青绿 / 水墨山水艺术示意切换。
- 韩愈、王正功诗句及徐悲鸿《漓江春雨》馆藏阅读卡，附中文原文/作品信息、本站英文释义、背景及原作来源链接。
- 《漓江春雨》阅读卡可一键带入题名、水墨配色、云雾与留白构图，明信片显示画意来源；导出的是本站原创山水创作。
- 明信片分山水创作与实景记忆。支持三种配色、三种构图、云雾、题字、小舟、署名与照片取景；导出1800×1260双语PNG，实景模式保留素材署名及授权。
- 用户主动开启的合成流水声，支持键盘和减少动态效果偏好。

## 内容与素材

参考来源在页面底部“资料来源与作品说明”及各板块中列明。主图：xiquinhosilva / Xiquinho Silva, Guilin Li River, CC BY 2.0。三处景点照片的作者、来源和授权记录在 `dist/content.js` 中；照片裁切/改编按各自许可保留署名及相同方式共享要求。程序山水为原创艺术示意，不是画家原作。徐悲鸿作品采用馆藏阅读与原作链接，不将本站插画冒充原作。地貌模型及水滴游戏为简化教学模型；百分比为动画进度，非年代。

## 文件

- `dist/index.html`：内容与双语文本
- `dist/style.css`：响应式页面样式
- `dist/experience.css`：新互动模块与移动端适配
- `dist/course.css`：全站双语排版、课程板块布局与响应式样式
- `dist/course-content.js`：文化词汇与双语英语介绍数据
- `dist/course-ui.js`：文化词汇选择与英语介绍生成交互
- `dist/experience-app.js`：景点、地貌、水滴路径、诗画和明信片交互
- `dist/fracture-model.js`：裂隙图、路径判定和动态路线提示的共用模型
- `dist/scenery.js`：原创山水绘图
- `dist/content.js`：真实景点、文化资料及素材署名
- `dist/assets/`：图片和标识
- `.openai/hosting.json`：Sites 发布配置

景点照片已更新：Bernt Rostad 的象鼻山水月洞、Gerd Eichmann 的九马画山正面岩壁、Liuxingy 的兴坪漓江峰林。来源和许可见 content.js。照片支持全景与轻量近景，路线图独立位于照片下方，避免遮挡山体和江面。
